# Caption Engine

Customize YouTube subtitles exactly the way you want.

YouTube Caption Styler is a powerful userscript for Tampermonkey and Violentmonkey that gives you full control over YouTube captions, including appearance, readability, accessibility, and advanced subtitle effects.

---

## Features

### Appearance

- Rounded caption backgrounds
- Blur and glass effects
- Custom fonts
- Font weight, spacing, scaling, and line-height controls
- Text shadows and outlines
- Gradient backgrounds
- Custom colors
- Border controls
- Position and width adjustments

### Presets

Includes built-in presets inspired by:

- Netflix
- TikTok
- Crunchyroll
- Blu-Ray subtitles
- Anime fansubs
- YouTube Classic (2014)
- Apple Liquid Glass
- Cyberpunk
- Steam Deck
- VHS
- Terminal
- Nordic Minimalism
- Windows XP

And more.

### Reading & Accessibility

- Reading Focus Mode
- Last-word highlighting
- Smart contrast adjustment
- Caption cleanup tools
- Filler-word reduction
- Whisper detection mode
- Adjustable subtitle opacity

### Fonts

- System fonts
- Google Fonts integration
- Custom font support
- Favorites and recent fonts
- Font preview picker

### Advanced

- Live updates without page refresh
- Preset saving and sharing
- Smart contrast engine
- Custom regex cleanup rules
- Full settings persistence

---

## Installation

### Step 1

Install one of the following:

- Tampermonkey
- Violentmonkey

### Step 2

Install the latest version of:

`youtube-caption-styler.user.js`

### Step 3

Open YouTube and start customizing captions.

## Philosophy

Most subtitle tools focus on appearance.

YouTube Caption Styler aims to improve both appearance and readability, allowing viewers to create subtitle experiences that match their preferences, accessibility needs, and viewing environments.
